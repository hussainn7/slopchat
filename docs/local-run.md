# Running SlopChat Locally

Follow these steps to run SlopChat on your machine for local development or testing.

## 1. Start the Datastores (Docker)

Make sure Docker Desktop is running. Spin up PostgreSQL and Redis:

```bash
docker-compose up -d
```

*Note: PostgreSQL is configured to run on port `5433` to avoid conflicts with any native PostgreSQL running on your Mac.*

## 2. Start the Local Tunnel (ngrok)

Open a terminal window and start ngrok to expose your local server to Meta:

```bash
ngrok http 3000
```

Copy the forwarding HTTPS URL generated by ngrok (it looks like `https://xxxx-xxxx.ngrok-free.app`).

## 3. Update the Environment Variables

Open `.env` in the root of the project and update the **`PUBLIC_URL`** variable with your copied ngrok URL:

```env
PUBLIC_URL=https://xxxx-xxxx.ngrok-free.app
```

*Keep `NEXTAUTH_URL=http://localhost:3000` as-is. This keeps your login session and magic link emails loading locally.*

## 4. Update the Meta App Dashboard

Whenever your ngrok URL changes, you must update the following in your [Meta Developer Portal](https://developers.facebook.com/apps):

1. **Instagram Business Login Settings:**
   * Update the **OAuth redirect URI** to:
     ```text
     https://xxxx-xxxx.ngrok-free.app/api/instagram/callback
     ```
2. **Instagram Webhook Settings:**
   * Update the **Callback URL** to:
     ```text
     https://xxxx-xxxx.ngrok-free.app/api/webhook
     ```
   * Use your existing `WEBHOOK_VERIFY_TOKEN` from `.env`.

## 5. Run the Application Processes

Open two separate terminal windows/tabs to run the web app and worker.

**Terminal 1 (Web Dashboard & API):**
```bash
npm run dev
```

**Terminal 2 (Background Worker):**
```bash
npm run worker
```

## Useful Diagnostic Commands

* Check the health of all systems:
  ```bash
  curl -s http://localhost:3000/api/health
  ```
* Stop the datastore containers:
  ```bash
  docker-compose down
  ```
